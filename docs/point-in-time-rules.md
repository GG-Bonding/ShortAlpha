# Point-in-Time 规则

这是 ShortAlpha 的最高优先级约束。因子引擎只回答一个问题：在信号时点，这条信息是否已经可以被使用。

宁可少一个因子，也不使用当时还看不到的数据。

## 1. 信号时点

默认：

```text
信号日 T 的 09:00 America/New_York
```

`T` 必须是 NYSE 交易日。周末、法定休市、配置里的额外休市，都不能生成信号，也不能被顺移到下一个交易日。提前收市不改变 09:00，只改变当日 bar 的 `available_at`。

夏令时由 `America/New_York` 处理。1 月的 09:00 是 14:00 UTC，7 月的 09:00 是 13:00 UTC。比较时间一律用带时区的时间，禁止 naive datetime。

## 2. 三个时间

每条进入研究库的记录都要有：

| 字段 | 含义 |
| --- | --- |
| `event_time` | 经济事件或行情区间本身发生的时间 |
| `published_at` | 数据源把它发布出来的时间 |
| `available_at` | 本系统允许使用它的时间 |

顺序必须是：

```text
event_time <= published_at <= available_at
```

提供者只有一个时间戳时，三个字段写成同一个值。禁止为了让记录“更早可用”而编造一个更早的 `available_at`。

准入规则只有一条：

```text
available_at <= signal_time
```

等于信号时点的记录可用。晚 1 秒不可用。

## 3. 例子

信号时点 `2025-04-10 09:00 ET`。

| 新闻 | published_at | 09:00 的信号 |
| --- | --- | --- |
| 正面 | 2025-04-10 08:30 ET | 可以使用 |
| 负面 | 2025-04-10 09:15 ET | 禁止使用 |

同一天 16:00 才收盘的日线，也不能给 09:00 的信号使用。

## 4. 各类数据的可用时间

### 日线

交易日 D 的日线：

- `event_time` = D 的官方收盘。常规 16:00 ET，提前收市 13:00 ET。
- `published_at` = 收盘。V0.1 不另建 SIP 延迟模型。
- `available_at` = 收盘。

因此 T 日 09:00 只能使用 `session_date <= T-1` 的日线，其中 `T-1` 是上一个交易日，不是日历上的昨天。

禁止把日线 bar 的起始时间戳当成 `available_at`。那会把收盘价泄漏给开盘前。

### 分钟线与盘前

分钟 bar 的 `available_at` 是该分钟结束，不是开始。09:00 的信号可以使用结束时间 `<= 09:00` 的 bar（即 08:59 那根），不能使用 09:00 开始的那根。

盘前窗口是信号日的 `[premarket.start, signal_time]`，默认 04:00 到 09:00 ET。历史对比窗口是更早交易日的同一时钟区间，而且那些 bar 自己也必须已经可用。这个条件在回放里自然成立，因为它们早于信号日。

`feed != sip` 时，系统不计算盘前成交量比率，并写入 `premarket_volume_available = false`。这是降级，不是一条成交量为 0 的假观察。同一窗口里的最后一笔 IEX 价格可以带时间进入价格确认，并标明它不是合并行情。

有 SIP、但该股票在窗口内没有成交：这是观察到的空窗，`volume = 0`，`last_price` 为空。价格行为因子不能由此编造价格。

### 新闻与事件

- `published_at` 使用源的 `created_at`。
- `available_at` 默认等于 `published_at`。
- 不知道独立的事件发生时间时，`event_time = published_at`。
- 新鲜度的年龄是 `signal_time - published_at`，单位小时，并且只用已准入的记录。
- 同一篇稿件后来的 `updated_at` 不参与过滤，理由见数据源决策。

### 向前收益是标签，不是特征

`Open(T)` 在 09:30 ET 之后才存在。09:00 的因子计算禁止读取：

```text
Open(T), High(T), Low(T), Close(T)
以及 T 之后任何交易日的行情
```

向前收益由单独的评估步骤，在这些 bar 的 `available_at` 已经过去之后计算。因子模块不能引用向前收益。

定义固定为交易日，而不是 `date + n days`：

```text
Return(n) = Open(T+n) / Open(T) - 1
ExcessReturn(n) = StockReturn(n) - SPYReturn(n)
```

`T+n` 是从 T 起第 n 个后续交易日。例如周五的 `T+1` 是下一个交易日周一；中间若有休市则继续顺延。

### 公司行动

拆分、分红只有在生效日 `<= T` 时才能使用。禁止用截至“今天”的前复权价格回放历史信号。V0.1 存储原始价格。窗口内部的收益要计入窗口内已经生效的拆分；窗口之外的未来拆分不得改变过去的价格水平。

### 指数成分

当前文件不是当时的成分。每次运行保存 `list_as_of` 和 `point_in_time_membership=false`。不得把这份文件描述成无幸存者偏差。

### 基准

SPY、QQQ、行业 ETF 使用与个股相同的已完成日线。信号日当天的基准收益不是特征。VIX 只有在存在 `available_at <= signal_time` 的报价时才参与市场状态；没有就标记 `vix_available=false`，禁止记成 0。

## 5. 因子允许看到的价格

信号日为 T，`C[D]` 表示交易日 D 的收盘，且该日线已通过准入。

```text
R1 = C[T-1] / C[T-2] - 1
R3 = C[T-1] / C[T-4] - 1
R5 = C[T-1] / C[T-6] - 1
```

动量只用已完成交易日。盘前价格只进入价格行为因子，避免同一段跳空被动量和缺口各记一次。

相对强弱的 5 日收益与 `R5` 同一窗口，个股、SPY、行业 ETF 都截止到 `T-1`。

流动性过滤：

```text
price = 盘前最后成交价，若该价格已可用；否则 C[T-1]
avgDollarVolume20 = mean(C[D] * V[D])，D 为 T-20 … T-1 这 20 个已完成交易日
```

成交量因子在不能使用盘前时：

```text
VolumeRatio = V[T-1] / mean(V[T-21] … V[T-2])
```

分母是信号日前 20 个已完成交易日，不含分子当天。分母为 0 或历史不足是错误，不是 0 分。

## 6. 缺失数据和 0 分

| 情况 | 行为 |
| --- | --- |
| Provider 报错、超时、返回非法数据 | 抛出错误。日志包含 symbol、provider、operation、timestamp、reason。该股票不评分 |
| 基准 SPY 或 QQQ 缺失 | 整次运行失败 |
| 个股日线不足 | 该股票不评分 |
| 行业 ETF 缺失或行业映射没有这只股票 | 该股票不评分 |
| 新闻接口成功但没有文章 | 有效空集。事件原始值为 0，不是故障 |
| 数据源不支持盘前 | 显式降级，不编造盘前量或盘前价 |
| 任何上述失败 | 禁止记成 0 分。0 分只表示因子公式算出来的低分 |

## 7. 回放

回放日 `T` 的信号时点就是当时的 09:00 ET。Provider 的每一次读取都带上这个 `as_of`。

禁止用“现在的数据库状态”直接重算过去而不做时间过滤。本地行情和新闻一旦写入就不可更新、不可删除。同一输入上的两次回放，快照正文的哈希必须相同；`run_id` 不同，旧快照保留。
